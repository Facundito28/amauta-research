12Datos y automatización
Borradores, JSON e IPC▸

El borrador guarda todo el estado y se puede volver a abrir acá. El JSON de skill sale en el formato que consume amauta-propuesta (sections[]), para renderizar el mismo informe desde Claude.

En la intranet, el generador intenta leer ./data/ipc.json y ./data/clientes.json al abrir. Si esos archivos existen, pisan estos valores y actualizás el IPC una sola vez para todo el equipo.
